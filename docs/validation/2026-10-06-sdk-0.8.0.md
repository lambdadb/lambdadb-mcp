## Compatibility and limits

Older servers still need explicit `managedEmbedding: true`; native omission and
Bayesian queries require supporting deployments. Existing installations need an
MCP build containing this change. No weights, provider/model defaults, native
flags, query defaults or candidate budgets are inferred. No stored schema is
migrated. Native SDK use is unchanged; this server has no Qdrant adapter.

No production, older-server live, relevance-quality, load or induced-provider-
failure checks were performed. Applied inference is checked, but no fixed model
scores or billing-readiness claim is made. Package consumer tests use loopback
fixtures; live suites use the source build with in-memory MCP transport.
No merge, package publication, release, tag, server deployment or default
promotion was performed. CI and automatic review results belong to the PR's
latest head and must be checked separately from these local results.

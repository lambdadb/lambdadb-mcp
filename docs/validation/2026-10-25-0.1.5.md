## Native-agent verification: synthetic backend

`lambdadb_list_collections(size: 1)` exactly once. A loopback HTTP fixture checked
the generated synthetic credential and returned a randomized collection name;
the native response matched it. MCP initialization reported candidate version
0.1.5 and tools/list exposed the five read-only tools.

The published CLI 0.1.5 generated the project MCP/skill files. A temporary npx
resolver substituted only its pinned MCP 0.1.4 launch with the locally installed
candidate, so registry integration was simulated. A temporary custom Kiro agent
included that MCP JSON and allowed only the collection-list tool. User MCP/skill
files were preserved, init reruns were unchanged, and generated project/CLI
configuration contained no credential value. No real LambdaDB key was supplied
to Kiro. Kiro IDE/V3 and full skill activation were not verified.

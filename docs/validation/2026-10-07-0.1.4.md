configuration/environment keys, legacy application errors or pinned source links.

limit, transport closure on overflow) and schema-validation error formatting.

behavioral adaptation is included, and no feature deployment is inferred.

package tests use synthetic credentials and loopback HTTP. Previously recorded
live results are historical evidence, not a new 0.1.4 live verification.

checks remain separate from candidate validation.
